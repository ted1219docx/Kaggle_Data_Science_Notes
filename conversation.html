def rmsle_clipped(y_true, y_pred):
    y_pred = np.clip(np.asarray(y_pred), 0, None)
    y_true = np.asarray(y_true)
    return np.sqrt(np.mean((np.log1p(y_pred) - np.log1p(y_true)) ** 2))

Assistant
The built-in RMSLE scorer uses y_true and y_pred as they are and errors on invalid negative values. The custom rmsle_clipped first clips negative predictions to zero, which is practical for positive targets like price. This changes the metric slightly because all negative predictions are treated as zero before scoring.

What does threshold = 'median' do?
Assistant
threshold='median' keeps transformed features whose fitted importance is at least the median feature importance. It therefore tends to keep roughly half the features, although ties can change the exact count.

Assistant
A numeric threshold such as 0.001 is unitless because Random Forest impurity importances are normalized to sum to 1. So 0.001 is about 0.1% of total impurity importance. You can tune selector threshold in GridSearchCV using regressor__select__threshold and then inspect selector.get_support().sum() to count retained features.
